# Review notes — Net (TLSStream, SMTPClient, IMAPClient, IMAPParser)

- C-01 | FIXED | Sources/Net/TLSStream.swift:48,120,227,243,364 | Added `discardBuffered()` to `ByteTransport`; `StartTLSTransport.startTLS()` now clears its run-loop-thread plaintext buffer atomically (same `onThread` block as the security-level switch) and `TLSStream.startTLS()` discards the transport buffer before the handshake, so pre-TLS bytes can no longer be served as if they arrived over TLS (fake-server test not added: Tests/ is out of scope for this worker).
- C-37 | FIXED | Sources/Net/IMAPClient.swift:341 | Empty Trash/Spam now uses `UID EXPUNGE 1:*` with UIDPLUS; otherwise it gates the bare EXPUNGE on `SEARCH DELETED` matching exactly the UIDs it just flagged, so another client's pending deletions are left alone.
- X-net-1 | FIXED | Sources/Net/IMAPClient.swift:499 | `expungeExactly` used an `isSubset` check while its comment promised an exact match, so a bare EXPUNGE could still permanently purge messages another client had flagged \Deleted (same data-loss class as C-37); it now requires equality and skips expunging otherwise.
- X-net-2 | FIXED | Sources/Net/IMAPParser.swift:346 | `imapQuoted` sent CR/LF verbatim, so a username, password or mailbox name containing them could inject extra IMAP commands; CR/LF are now stripped (they are illegal inside an IMAP quoted string anyway).

Verification: `MAC_MAIL_BUILD_DIR=build MAC_MAIL_ARCHS=arm64 ./build.sh debug` builds clean. `tools/selftest.sh` reports 10 failures, but they are environment-caused and pre-existing: a probe shows this sandbox denies `mkdir` under `NSTemporaryDirectory()` (`Operation not permitted`), which cascades into the eml/inline/store/outbox tests whose `try?` fixture writes are silently dropped; TMPDIR does not help because `NSTemporaryDirectory()` ignores it on this macOS. The failure set is byte-identical when the selftest is compiled from pristine HEAD (git archive) sources, so the Net changes introduce no regressions; Net behaviour itself is not covered by any failing test.
